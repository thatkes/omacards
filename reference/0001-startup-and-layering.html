Qt vocabulary

TermMeaning in this repo
QObjectBase class whose properties, methods and signals Qt can introspect and expose to QML.
Q_PROPERTYA C++ member readable/writable from QML as a property; changes can emit a notify signal.
Q_INVOKABLEA C++ method callable from QML/JS.
Context propertyAn existing C++ object made visible by name in the QML root context.
qrc:/Qt resource path — files compiled into the binary.
offscreenQt platform plugin with no window; used by the CLI and the test suite.
qmake6Qt's build-file generator; reads omacards.pro.

Build & verify

./bin/build    # qmake6 omacards.pro && make -j$(nproc)
./bin/test     # qmake6 tests.pro && make && QT_QPA_PLATFORM=offscreen ./omacards_tests

Tests compile the real src/*.cpp (except main.cpp and traycontroller.cpp) into the test binary — see tests/omacards_tests.pro. CLI integration tests skip unless build/omacards exists, so build first. CI does exactly build → test: ci.yml.

Isolation variables

OMACARDS_DECKS_DIR=/tmp/...     # deck files live here
OMACARDS_STATE_DB=/tmp/...      # SQLite sidecar lives here

Resolved once in backend.cpp:21–29. Both GUI and CLI use them so agents and tests never touch real study data.
